# DELTARUNE Thai localization
ยินดีต้อนรับสู่ DELTARUNE ฉบับปรับให้เหมาะกับท้องถิ่นไทย ซึ่งเป็นการแปลภาษา DELTARUNE แบบรู้บริบทและทำให้ตรงตามเจตนาต้นฉบับให้มากที่สุดเท่าที่เป็นไปได้

# การสร้างสภาพแวดล้อมเพื่อการพัฒนา

## ข้อกำหนด

ก่อนคุณสร้างสภาพแวดล้อมเพื่อการพัฒนา คุณต้องมีซอฟต์แวร์เหล่านี้ในเครื่องของคุณ
- ระบบปฏิบัติการ(เสมือน)ยูนิกซ์
- GNU Utilities
- UndertaleModTool (ฉบับ CLI)
- Python 3
- Krita
- pngquant
- DELTARUNE

## การติดตั้ง

คัดลอกโฟลเดอร์ DELTARUNE มาไว้ในไดเรกทอรีปัจจุบันที่ท่านอ่านไฟล์นี้อยู่

หากคุณมี UndertaleModCLI อยู่ใน `PATH` คุณอยู่แล้ว ให้รันคำสั่งนี้

`./build.sh`

หากคุณไม่มี UndertaleModCLI ใน `PATH` ของคุณ ให้รันคำสั่งนี้

`./build.sh -b "/เส้นทาง/ว่า/ไดเรกทอรี/UndertaleModCLI/อยู่ส่วนไหนของโลก/"`

## โครงสร้างไดเรกทอรี

เนื่องจากการแก้ไขเกม DELTARUNE เป็นอะไรที่ซับซ้อนมากมาย เพื่อเป็นการจัดระเบียบไฟล์ให้เรียบร้อยและทำให้สามารถขยาย DELTARUNE เพิ่มเติมได้เมื่อมีการอัปเดตใหม่ จึงมีไดเรกทอรีและไฟล์ดังนี้

```
@ root directory
/patches/           # ไฟล์แพตช์เพื่อการสร้างสภาพแวดล้อม
    /diff/          # ไฟล์ diff ที่ได้มาจาก DELTARUNE (แต่ไม่มีรหัสต้นฉบับของ DELTARUNE)
    /etc/           # ไฟล์ต่าง ๆ ที่ไม่ได้มาจาก DELTARUNE
/scripts/           # ไดเรกทอรีสคริปต์ของ UndertaleModTool ที่ต้องใช้ในการแพตช์
/sprites/           # ไดเรกทอรีสไปรต์ทั้งหมด
/sprites-raw/       # ไดเรกทอรีสไปรต์ที่ยังไม่ได้ทำไปนำออกเป็นสกุลไฟล์ PNG
build.sh            # สคริปต์เพื่อการจัดการสภาพแวดล้อมการพัฒนา
README.md           # ไฟล์นี้
AGENTS.md           # ไฟล์กัน LLM ช่วยงาน

เมื่อเริ้มต้น build.sh เป็นครังแรกแล้ว
คุณจะได้สภาพแวดล้อมเพื่อการพัฒนาดังนี้

/modifications/       # รหัสทั้งหมด
/extracted/           # ข้อมูลไฟล์ต่างๆ ที่ได้มาจาก DELTARUNE

```

## ด้านภาษา
หากคุณอยากมีส่วนร่วมในโครงงานนี้ในฐานะผู้ที่เกี่ยวกับงานทางด้านภาษา (นักแปล, เกลี่ยภาษา, ผู้แสดงความเห็น, และผู้เสนอแนะ) คุณสามารถเข้าไปยัง[บริการแชตกรรมสิทธิ์ Discord](https://discord.gg/p5wuX5GwB7) เพื่อเริ่มอภิปรายได้

## ด้านซอฟต์แวร์
หากคุณอยากมีส่วนร่วมด้านซอฟต์แวร์ คุณต้องทำตามนโยบายเหล่านี้

1. การทำตามสัญญาอนุญาต
    - คุณยอมรับว่าคุณจะปฏิบัติตามนโยบายสัญญาอนุญาตของโครงงานนี้
    - คุณยอมรับว่าหากคุณไม่ปฏิบัติตามนโยบายตามสัญญาอนุญาตดังกล่าว คุณอาจถูกเพิกถอนการใช้งาน และการเข้าถึงซอฟต์แวร์นี้อย่างถาวรได้
2. การใช้งานปัญญาประดิษฐ์
    - ในโครงงานนี้ ผู้จัดทำมองรหัสต้นฉบับเป็นงานศิลปะแห่งการเขียนโปรแกรม หากคุณสั่งให้ซอฟต์แวร์ทำอะไรให้คุณไปเรื่อย ๆ แล้วคุณจะขีดเส้นแยกระหว่าง "คุณสร้างเอง" กับ "สั่งทำ" ตรงไหนล่ะ และคุณควรย้อนมาถามด้วยว่าคำว่า "สิ่งสร้างสรรค์" นั้น มีความหมายอย่างไรในสายตาของคุณ
    - หากคุณต้องการมีส่วนร่วม คุณเอง**จำเป็นต้องมอง**ในมุมมองเดียวกันเช่นกันกับผู้อื่นในโครงงานนี้ ฉะนั้นจึงมีข้อตกลงอย่างง่ายดายสำหรับผู้ที่อยากมีส่วนร่วม
    - คุณยอมรับว่าคุณจะ**ไม่ใช้งาน**แบบจำลองภาษาขนาดใหญ่ (หรือนิยามภาษาอังกฤษเป็น "Large Language Model") ไม่ว่าจะเป็นจักรกลสนทนา (นิยามภาษาอังกฤษ "Chatbot") โปรแกรมตัวแทน (นิยามภาษาอังกฤษ "Agents") หรือการจำแนกแบบจำลองภาษาขนาดใหญ่ชนิดอื่น ในการมีส่วนร่วมด้านซอฟต์แวร์ในโครงงานนี้
    - ในไฟล์ [AGENTS.md](AGENTS.md) ผู้จัดทำได้ใส่คำเตือนดักไว้ **ไม่ได้จัดทำเพื่ออนุเคราะห์การใช้งานแบบจำลองภาษาขนาดใหญ่ใด ๆ** แต่มีจุดประสงค์เพื่อการดักบุคคลที่มิได้อ่านไฟล์ README และสุ่มสี่สุ่มห้าไปใช้โปรแกรมตัวแทนเท่านั้น
3. การส่งคำขอ Pull Request
    - ส่งรหัสต้นฉบับ**ที่คุณเข้าใจ** และคุณ**พิมพ์ด้วยตนเอง**เท่านั้น
